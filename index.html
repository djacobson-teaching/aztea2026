01 · Decide this first

Two kinds of things.

  • Form answers become filled docs, filed in Drive and emailed out
  • Mail merge straight from a sheet
  • Rename and sort a folder of files
  • Clean up a tracker every night on its own
  • A dashboard your team checks
  • A picker or scoreboard for the projector
  • A form that looks like something, not a Google Form
  • A self-paced review activity

You always get a Code.gs. You only add an HTML file when there's something to look at.

02 · The whole workflow

Describe it. Paste it. Run it.

01Describe it in a chatPlain language. Say what it does and what's in your sheet.
02Copy the codeCode blocks have a copy button in the corner. If you downloaded a file instead, right-click it and Open with Notepad or TextEdit. Never double-click it. An .html file opens as a web page and the code disappears.
03Paste it into Apps ScriptInto the file it told you to.
04Save, then run itSomething will break. That's normal.
05Paste the error backCopy whatever turned red and say "this is the error I got."

↻  Then go again. That loop is the entire skill.

04 · Start every build with this

The ask.

I want to build an automation in Google Apps Script. No web page. I run it from my spreadsheet. Here is what it should do: [what it does, in plain language] My sheet is [paste the URL] and the columns are [A is Name, B is Date, etc.] Give me each file separately with its file name, plus setup steps for someone who has never used Apps Script. Add a custom menu so I can run it from the spreadsheet toolbar.
I want to build a web app in Google Apps Script. People open a link and use it on a page. Here is what it should do: [what it does, in plain language] My sheet is [paste the URL] and the columns are [A is Name, B is Date, etc.] Give me each file separately with its file name, plus setup steps for someone who has never used Apps Script. Apps Script only allows .gs and .html files, so put all the CSS and JavaScript inside the HTML file and use google.script.run for any call from the page to a server function.

06 · Where the code goes

Opening Apps Script.

01

Open your sheet. Click Extensions, then Apps Script.

Start from the sheet and the script already knows which sheet it belongs to. That saves you a step later.

02

You land on a file called Code.gs.

Select everything in it and paste yours over the top. Delete the empty myFunction it ships with.

03

Need a second file? Click the + next to Files.

Choose HTML for a page, Script for more code. Type the name with no extension. Index, not Index.html.

04

Save.

Ctrl+S or the disk icon. Nothing happens until you do.

07 · Making it go

Run it or ship it.

Automation

  1. Pick your function name from the dropdown at the top.
  2. Click Run.
  3. First time only: Advanced, then Go to (unsafe), then Allow.

Ask for a custom menu and it shows up in your spreadsheet toolbar instead. Then anyone can run it.

Web app

  1. Deploy, then New deployment, then Web app.
  2. Execute as Me (this is what lets other people's browsers read your sheet without giving them the sheet). Access: Anyone.
  3. Authorize the same way, then copy the URL.

That link is your tool. Anyone can open it.

Changed your code after deploying? Save, then Deploy → Manage deployments → pencil icon → Version: New version → Deploy. Saving alone does not update your live link. This one gets almost everybody.
